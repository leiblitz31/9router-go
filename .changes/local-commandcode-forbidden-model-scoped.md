- Command Code 403 `FORBIDDEN` refusals (retired free tier, unrecognized model id) are now classified as model-scoped in the chat fallback and combo paths: only the offending model is locked, instead of parking the whole connection behind a rate-limit cooldown that made every healthy `cmc/*` model answer 502. Mirrors the intent of upstream decolua/9router#3894 (request-scoped schema errors must not lock accounts) for Command Code's structured error envelope. Verified by `TestIsCommandCodeModelRefusal` plus live probes: a deliberate bad-model 403 no longer cools the connection, and the healthy models keep answering 200.
