### Features

- **dashboard**: proxy pools can now be created and edited as DNS-over-HTTPS (DoH) pools. The pool form gains a Standard/DoH type selector; DoH mode replaces the proxy URL and No Proxy fields with a resolvers textarea (one spec per line — an alias such as `cloudflare`, `google`, `quad9`, `adguard`, or a full `https://…/dns-query` URL), and pool rows label a DoH pool with its first resolver (plus a count of the rest) instead of a blank URL. Editing an existing DoH pool reopens in DoH mode with its resolvers intact, and saving one as a standard proxy again restates the type and clears the specs.
- **dashboard**: `POST /api/proxy-pools` now stores a DoH pool's resolver list — the create payload's `urls` were parsed and then dropped before reaching the stored pool data, so a DoH pool could not be created intact — and refuses a DoH pool that names no resolver; updating a pool to type `doh` clears any stale proxy URL from its stored data.
- **dashboard**: testing a DoH pool probes DNS through the pool's own resolvers (new `proxy.ProbeDoHResolvers`, wrapping the resolver's existing failover; `cloudflare.com` is the probe name) and stores the verdict and latency like any other pool test, instead of dialing a resolver spec such as `cloudflare` as an HTTP proxy and reporting a healthy pool dead.
