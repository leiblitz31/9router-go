### feat(cursor): resolve Auto alias, recover empty turns, hold strictProxy in media lanes, pin Copilot embeddings

- **Auto (Server Picks) resolve (#4692):** `cursor/default` and `cursor/auto` are picker aliases, not AgentService model ids — forwarding them literally gets a 200 with an empty turn. `resolveModel` now maps them to the registry's first concrete cursor model (fail-open: unknown/other providers pass through untouched).
- **Empty-turn recovery (#4690):** a long session (80+ replayed messages, `CURSOR_TAIL_ONLY_THRESHOLD`) whose full replay returns 200 with no completion is retried once on a tail-only frame (system prompts + latest 8 turns + trim notice) before failing the turn. Short sessions surface the kernel's 502 untried; streaming turns are excluded (headers commit before the first chunk). Knobs: `CURSOR_EMPTY_TURN_MAX_RETRIES` (1), `CURSOR_TAIL_ONLY_THRESHOLD` (80), `CURSOR_EMPTY_TURN_RETRY_DELAY_MS` (400).
- **strictProxy hold in media lanes (#4696):** the 4 manual `directHTTPClient` direct-retry paths (media generic, antigravity search, xquik search, `doDirectOrClient` TTS) now skip the retry when the connection's client carries the strict marker, so a strict pool failure surfaces instead of answering from the host's real IP.
- **Copilot embeddings pin (#4793):** verified `github` BaseURL is already `https://api.githubcopilot.com/chat/completions`; replaced the unsupported `text-embedding-3-large` with `text-embedding-ada-002` in the `gh`/`github` model lists and kind map, and forward `StaticHeaders` (IDE headers) on the embeddings lane.
